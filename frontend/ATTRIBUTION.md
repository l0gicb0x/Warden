# Attribution

This project incorporates third-party UI code that has been copied or adapted into the repository rather than installed via a package manager.

- `src/components/ui/*`: Contains components generated by [shadcn/ui](https://ui.shadcn.com/).
- `src/components/aceternity/*`: Contains components adapted from [Aceternity UI](https://ui.aceternity.com/).
- `src/components/magicui/*`: Contains components adapted from [Magic UI](https://magicui.design/).

All other directories under `src/` contain first-party code written specifically for Warden.
